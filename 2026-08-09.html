① Claude Code 将默认启用 Auto Mode，并新增跨会话消息功能

8月14日起，Claude Code 的默认权限模式将切换为 Auto Mode（自动模式），官方称此举旨在提升开发效率。同时，Claude Code 会话间现在可以互相发送消息，实现多终端协作工作流。

  • 日期：2026-08-07（Auto Mode）/ 2026-08-08（跨会话消息）
  • 来源：The New Stack / Claude Code 官方文档
  • 链接：https://thenewstack.io/claude-code-auto-mode/
  • 链接：https://code.claude.com/docs/en/cross-session-messaging

② Kimi K3 正式登陆 GitHub Copilot

月之暗面（Moonshot AI）的 Kimi K3 模型现已可在 GitHub Copilot 中作为代码补全和聊天模型使用，进一步丰富了 Copilot 的模型生态。

  • 日期：2026-08-06（扩展至72小时范围）
  • 来源：GitHub Blog
  • 链接：https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/

③ Qwen3.8-Max 登顶 Artificial Analysis Agentic Index

Qwen3.8-Max 在 Artificial Analysis 的 Agentic Index（智能体能力指数）综合评分中排名第一，超越多个竞品模型，成为当前智能体任务综合能力最强的模型。

  • 日期：2026-08-06
  • 来源：Artificial Analysis
  • 链接：https://artificialanalysis.ai/?intelligence=agentic-index

④ DeepSeek V4 Flash 0731 在 ARC-AGI 取得突破性成绩

DeepSeek V4 Flash 0731（284B参数，1M token上下文）在 ARC Prize 基准测试中取得显著进展，获得社区 754 点高赞。该模型采用 latent reasoning（潜在空间推理）技术，目前免费使用。

  • 日期：2026-08-07
  • 来源：ARC Prize
  • 链接：https://arcprize.org/results/deepseek-v4-flash-0731
