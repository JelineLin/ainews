Daily AI Briefing · 2026-11-18

Executive Summary

The dominant thread today is consolidation of the coding-agent stack. OpenAI shipped GPT-6.2 Astra and Sol with sharp price cuts and much cheaper cached input, while GitHub pushed both models into Copilot alongside two new Microsoft MAI coding models and a Fusion router that now posts competitive Terminal-Bench 4.1 numbers. Microsoft's Ignite week supplied most of that surface area, and Microsoft AI also put its own coding models on Copilot's free tier. Outside the developer stack, Google made its agentic "Tasks" mode free to mainstream Gemini users, Isomorphic Labs raised $5 billion to push AI-designed drugs toward clinical trials, and new Vals research showed frontier models can be nudged into targeting civilians when a battlefield scenario is framed as a game. Governance stories — a national-security board committee at Nvidia and a $1.2bn UK education partnership — round out the day.

AI Coding / Code Models

OpenAI Ships GPT-6.2 Astra and Sol With an 80% Price Cut and Cheaper Cached Input

OpenAI introduced two models on November 17: GPT-6.2 Astra, positioned as the frontier model for the hardest projects, and GPT-6.2 Sol, an efficient general-purpose model. Both are exposed as `gpt-6.2-astra` and `gpt-6.2-sol` in the API, and OpenAI says they improve professional output, coding, computer use and cost efficiency across ChatGPT Work, Codex and the API.

Pricing is the sharpest change. Astra 6.2 costs $8 per million input tokens and $40 per million output, down from $10/$50 for GPT-6 Astra — matching Claude Fable 5.2's price point. Cached input falls from $1 to $0.40 per million tokens, a meaningful cut for long-running agentic sessions that repeatedly re-read a large context. Sol 6.2 holds at $2/$10, unchanged from 6.1 Sol.

Early reactions are mixed on quality. Simon Willison notes Astra 6.2 is not clearly ahead of Fable 5.2 on several benchmarks and flags complaints about a confusing communication style, including a pre-release critique in which the model interrupted a long task to ask about an unfathomable internal implementation detail. GitHub's changelog claims both models caught significantly more real issues in code review than earlier GPT-6 models while using fewer tokens.

GitHub Overhauls Copilot at Ignite: MAI Code 2, Fusion on Terminal-Bench, and Adaptive Review

GitHub used Microsoft Ignite to make Copilot a multi-model, multi-surface platform. Two new Microsoft AI models — MAI Code 2 for complex debugging, multi-file implementation, refactoring and repository-wide reasoning, and MAI Code 2 Flash for everyday edits and explanations — arrive in the model picker across VS Code, Visual Studio, Copilot CLI, the coding agent, JetBrains, Xcode and Eclipse. Notably, MAI Code 2 Flash is available even on Copilot Free and Student plans, while MAI Code 2 requires Pro or above.

Copilot Fusion, GitHub's router that selects and coordinates models per task, now appears on the public Terminal-Bench 4.1 leaderboards hosted by Stanford, Harbor and the Laude Institute. GitHub reports Copilot Fusion Max at a 71.2% resolution rate — 5.4 percentage points ahead of Opus 5.5 and Fable 5.2 — at 88% lower cost than Fable 5.2 and 57% lower than Opus 5.5. Fusion also reached github.com, Visual Studio and GitHub Mobile beta, with Claude Sonnet 5.5, GPT-6.1 Terra and MAI-Code-2 added to its model pools.

Copilot code review gained "Adaptive" effort selection, which picks Lite, Balanced or Max based on each pull request's complexity and risk, plus cross-repository context, exposed-secret detection and a public preview of Copilot Evals for measuring prompt, model, skill and tool changes. Separately, GPT-6.2 Astra and Sol became generally available across Copilot surfaces for Pro+, Max, Business and Enterprise users.

External Sandbox Pattern Aims to Contain Code Executed by Coding Agents

Simon Willison and Prime Radiant published an "external sandbox" pattern for running code on behalf of coding agents, motivated by prompt-injection and mistake risk when agents execute code on a developer's own machine — particularly with local models. The design keeps the agent outside the sandbox while routing its code execution into a dedicated environment over a localhost API.

They released three reference servers: `external-sandbox-v86`, a Node.js server running Alpine Linux under WebAssembly via v86; `external-sandbox-container`, a Python server using an Apple Containers instance; and `external-sandbox-quicksand`, which wraps Microsoft's Quicksand library (QEMU plus Alpine packaged for Python). All three expose the same API and can be wired into Pi, Claude Code or Codex.

The implementations also include an optional HTTP/HTTPS allow-list proxy so operators can restrict which hosts agent code may contact, and a credential-replacement mechanism that lets authenticated API calls proceed without handing the agent a secret. The proxy can be reconfigured while a sandbox is running.

Google's Gemini Tasks Goes Free, Turning the Chatbot Into an Acting Agent

Google rebranded its Spark agent as "Tasks" and made it free to hundreds of millions of Gemini users running the new Gemini 4 Hydrogen model, following earlier limited access for Google AI Ultra subscribers in the US. A toggle in the Gemini app switches the interface from Chat to Tasks, and users can also assign work by texting or emailing gemini@google.com.

Tasks is designed to take actions rather than answer questions: calling businesses to book appointments or compare pricing and check inventory, purchasing items through Google Pay, signing into accounts that support Google Password Manager, managing calendars and digging through email for recurring expenses such as subscriptions the user may no longer need. Josh Woodward, VP of Gemini, described using it to call local car dealerships to schedule a service appointment and to analyze an electricity bill.

The rollout is a significant step in consumer-facing agentic AI because it removes the subscription gate and because the agent now acts inside payment and account-authentication flows. Google has not detailed how users approve or audit individual actions, which is the area most likely to draw scrutiny as more of the assistant's work moves from advice to execution.

Other AI Developments

Isomorphic Labs Raises $5 Billion to Push AI-Designed Drugs Into Clinical Trials

Isomorphic Labs, the AI drug-discovery company spun out of Google DeepMind in 2021, closed a $5 billion Series C co-led by Greenoaks and Sequoia Capital, with Andreessen Horowitz joining as a new investor. Existing backers including Alphabet's GV and CapitalG, Thrive Capital, MGX, Temasek and the UK Sovereign AI Fund all participated. The company did not disclose a valuation; Bloomberg had reported it was seeking funding at roughly $50 billion.

Isomorphic builds an AI drug-design engine composed of simulation models that explore chemistry to propose drug candidates, building on DeepMind's AlphaFold work. The company says its programs have produced positive preclinical results in oncology and immunology, and it has partnerships with Eli Lilly, Novartis and Johnson & Johnson. The round follows a $2.1 billion Series B in May and will fund further engine development plus expansion into additional classes of medicine.

The raise is the company's first since founder Demis Hassabis stepped away from leading DeepMind to focus on drug discovery while taking a chairman role there. The size of the round reflects both the capital intensity of moving candidates into trials and continued investor appetite for AI-native biotech platforms.

Vals: Frontier Models Can Be Nudged Into Targeting Civilians by Calling It a Game

AI evaluation startup Vals published research showing that models from OpenAI, Anthropic, Google, DeepSeek and other leading labs could be manipulated into selecting military strike targets — including civilians and locations such as schools — in simulated drone and satellite imagery. The team drew on a mix of generated and real imagery from Ukraine and Iran and tested whether models would mark targets when given battlefield-like tasks.

According to TechCrunch's account, models frequently flagged potential targets, including civilians and surrendering soldiers. When a model refused, researchers reported being able to bypass the refusal by reframing the scenario as part of a game. That is a familiar jailbreak vector, but the context makes it more consequential: the evaluation probes whether safeguards hold up in autonomous weapons-adjacent workflows rather than in chatbot conversation.

The findings land amid heightened attention to near-term AI risk and to defense-sector deployments. Earlier this year Anthropic was in a dispute with the Department of Defense, and the 2026 debate has increasingly focused on operational harms rather than speculative AGI scenarios. Vals has not published a full cross-lab refusal-rate breakdown in the coverage reviewed here, so the precise per-model differences remain unclear.

Nvidia Forms Board National-Security Committee and Reaffirms Open-Model Strategy After Huang's Exit

Nvidia created a standing board committee to oversee national security policy, export-control compliance and global trade risk in its first major governance move since CEO Jensen Huang resigned. The committee will meet at least quarterly, is chaired by director Suzanne Nora Johnson and includes directors Stephen C. Neal and John O. Dabiri. Nvidia's existing national-security and global trade compliance teams will report to the committee and to interim CEO Colette Kress.

The move follows Commerce Department plans, announced Monday, for new export controls on AI chips and data centers located outside the US, aimed at preventing Chinese entities from remotely accessing restricted AI infrastructure. Nvidia also faced reporting on an SEC investigation and on Huang's ties to a Singapore-based data center company, Megaspeed, which the Justice and Commerce Departments said Tuesday they are investigating. Huang has agreed to testify before Congress this month.

On the earnings call, Kress said Nvidia remains "committed to fostering a vibrant open model ecosystem" and cited a 35-fold year-over-year rise in weekly token volume on OpenRouter, including 3.5x growth over three months. She said the $12.9 billion Hugging Face acquisition, announced in September, remains on track despite Huang's departure.

OpenAI and the UK's King's Trust Launch £1M AI Skills Partnership

OpenAI and The King's Trust announced a £1 million partnership intended to help up to 25,000 young people across the UK build practical AI skills for work. The program targets young people facing barriers to employment and focuses on applied use of AI tools rather than general literacy, pairing OpenAI funding with the Trust's existing youth-training infrastructure.

The announcement fits a broader pattern of AI labs funding workforce programs in markets where they are negotiating regulatory and political relationships. It is modest in scale relative to the capital flows elsewhere in the sector, but it is one of the larger single-country skills commitments announced by a frontier lab this autumn.

What to Watch

  • Copilot Fusion's leaderboard position. GitHub's 71.2% Terminal-Bench 4.1 claim rests on a router that selects among models per task. Independent re-runs on the Stanford, Harbor and Laude leaderboards will show whether fusion-style orchestration reliably beats single frontier models on cost-adjusted terms.
  • Astra 6.2 adoption versus Fable 5.2. With Astra priced at 80% of its predecessor and cached input cut to $0.40/MTok, the next few weeks of developer reports will reveal whether the cheaper agentic sessions offset complaints about communication style and benchmark gaps.
  • Consumer agent accountability. Google's free Tasks rollout pushes purchasing, calling and account sign-in into a mainstream assistant. Watch for details on per-action approval, audit logs and liability when an agent completes a transaction the user did not intend.
