【AI Coding / Code Models】

1. Meta 发布首个 AI 编程 Agent "Muse Code"，正面挑战 Anthropic 与 OpenAI

Meta 正式推出其首个 AI 编程 Agent Muse Code，同时发布了 Muse Spark 1.2 更新。Muse Code 定位为可直接与 Claude Code、Codex 等竞争的 Coding Agent，标志着 Meta 在 AI 编程工具赛道上的正式入局。该消息在 Hacker News 上获得 321 个点赞，引发广泛讨论。

  • 发布日期：2026年8月5日
  • 来源：Meta AI Research Blog
  • 原文链接：https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2

2. Kimi K3 模型正式登陆 GitHub Copilot

GitHub 官方宣布，Kimi K3 模型现已在 GitHub Copilot 中可用。开发者可以在 Copilot Chat 和 Copilot 代码补全中选择使用该模型，进一步丰富了 Copilot 的模型选择生态。

  • 发布日期：2026年8月6日
  • 来源：GitHub Blog Changelog
  • 原文链接：https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/

3. JetBrains IntelliJ IDEA 引入 LSP 协议，Java/Kotlin 智能代码分析登陆 VS Code 和 Cursor

JetBrains 宣布其 IntelliJ IDEA 引擎支持 Language Server Protocol (LSP)，使得 Java 和 Kotlin 的高级代码智能（重构、导航、检查）能够在 VS Code、Cursor 等编辑器中直接使用。这是 JetBrains 开放其核心 IDE 能力的重要一步。

  • 发布日期：2026年8月4日（扩展 72 小时范围，已标注）
  • 来源：JetBrains Blog
  • 原文链接：https://blog.jetbrains.com/idea/2026/08/intellij-idea-goes-lsp/

5. AMD 收购 AI 芯片硬编初创公司 Taalas
