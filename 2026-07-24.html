【AI Coding / Code Models】

1. BTL-3：27B 开源权重 Agent 编码模型发布

badtheorylabs 发布 BTL-3，一个 27B 参数的开源 Agent 模型，专为 Agentic Coding 和结构化工具调用设计。该模型在 HuggingFace 上公开，定位为可用于编码 Agent 工作流的轻量级开源替代方案。

2. JetBrains Context：为 Coding Agent 打造的仓库智能层 ⏰ 近72小时

JetBrains 发布"JetBrains Context"，这是一个为 AI 编码 Agent 提供代码仓库级别智能理解的新服务。它能将仓库结构、依赖关系和代码语义转化为 Agent 可消费的结构化上下文，帮助编码 Agent 更准确地理解项目整体架构，而非仅关注当前文件。

3. OneCLI：开源凭证安全网关，防止 AI Agent 泄露密钥

开发者发布 OneCLI，一个开源凭证安全网关，作为网络代理层防止 Prompt Injection 窃取 API 密钥和敏感凭证。支持 Claude Code、Codex、Cursor 等主流 AI 编码工具，为 AI 编码 Agent 提供企业级安全边界。
