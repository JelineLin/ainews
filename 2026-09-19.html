AI 每日简报 · 2026-09-19

今日总览

今日主线仍是 Coding Agent 的工具链迭代：Claude Code 与 Codex 双双发版，Claude Code 开始原生读取业界通用的 AGENTS.md，Codex 则回滚了默认推理摘要以避免兼容性问题；GitHub 把 Copilot 代码审查升级为正式版。安全侧出现标志性事件——研究者用 Claude 攻入 OpenAI 内部，凸显 AI 攻防的新形态。

【AI Coding / Code Models】

1. Claude Code v2.1.277：新增 AGENTS.md 支持，跟进跨厂商通用规范

Claude Code 发布 v2.1.277，最值得关注的是原生支持 AGENTS.md：当项目里没有 CLAUDE.md 时，Claude Code 会改读 AGENTS.md，可在 `/config` 的 "Project instructions" 中切换（目前 Bedrock、Vertex、Foundry 尚不支持）。这意味着它开始兼容 OpenCode、Codex 等工具推动的跨厂商 Agent 指令标准，多工具混用的团队无需再维护两份配置。同版本还修复了 `claude -p` 与 Agent SDK 会话在内部错误后无结果挂起、以及空文本块导致每轮请求失败等问题。

  • 发布日期：2026-09-18
  • 来源：GitHub · anthropics/claude-code Releases
  • 链接：https://github.com/anthropics/claude-code/releases/tag/v2.1.277

2. OpenAI Codex CLI v0.155.1：默认关闭 TUI 推理摘要以修复兼容性问题

Codex 发布 rust-v0.155.1 补丁版，把新建本地 TUI 会话的推理摘要（reasoning summary）默认改为关闭，原因是部分不支持该能力的模型提供方会直接拒绝请求；用户显式的推理摘要设置仍然生效。这是对前一天 v0.155.0 新增 "TUI 状态栏实时推理摘要" 的快速回滚修正，也说明新交互特性在跨 provider 场景下的兼容性仍需打磨。

  • 发布日期：2026-09-18
  • 来源：GitHub · openai/codex Releases
  • 链接：https://github.com/openai/codex/releases/tag/rust-v0.155.1

3. GitHub：Copilot code review 改进体验正式 GA，10 月将下线一批旧模型

GitHub 宣布 Copilot 代码审查的三项改进正式可用（GA）：概览评论现在会展示 Copilot 对 PR 的当前判断、所用审查力度以及发现项汇总，并随时间跟踪变化；Copilot 能更聪明地自动解决自己提过的建议；批量接受建议时会生成更有意义的 commit message。同日 GitHub 还公告将于 2026 年 10 月 19 日在所有 Copilot 体验（Chat、inline edits、ask/agent 模式与代码补全）中下线一批选定模型，提醒团队提前迁移到推荐替代模型。

  • 发布日期：2026-09-18
  • 来源：The GitHub Blog · Changelog
  • 链接：https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience
  • 链接：https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october

7. RLHF 发明人推出非语言模型 Jev：不输出文本，从源头消除幻觉

曾参与打造 ChatGPT、并参与发明 RLHF 的 OpenAI 前研究者 Diogo Almeida，与 Erik Gafni、Sasha Sheng 共同创办的 TypeSafe AI，本周发布基于 Transformer 但非 LLM 的新模型 Jev：它不生成文本，而是输出概率即"校准后的决策"。由于输出由用户预先定义，模型结构上无法产生幻觉，且速度极快、输出 token 免费、输入按"十亿 token"而非"百万"计费，主要面向软件自动化。发布后 API 一度因需求过高而短暂不可用。

  • 发布日期：2026-09-18
  • 来源：TechCrunch
  • 链接：https://techcrunch.com/2026/09/18/a-new-kind-of-ai-model-from-a-chatgpt-inventor-is-thrilling-developers/

8. Alibaba Qwen 发布 Qwen3.8-Omni-Flash：首个以 Agent 能力为核心的全模态模型

通义千问发布 Qwen3.8-Omni-Flash，官方称其为首个围绕 agentic 能力构建的全模态模型：接受文本、图像、音频、视频输入，统一完成理解、推理与工具调用。上下文窗口达 100 万 token（最大输入 991K、输出 131K），最大推理长度 262K，默认开启思考（reasoning_effort=xhigh）。目前仅提供托管 API（QwenCloud / 阿里云百炼 / Qwen Studio），未公布开源权重，无法自部署。

  • 发布日期：2026-09-18
  • 来源：MarkTechPost
  • 链接：https://www.marktechpost.com/2026/09/18/alibaba-qwen-releases-qwen3-8-omni-flash/

值得持续关注的趋势

1. Agent 指令规范走向统一：Claude Code 开始读取 AGENTS.md，说明跨工具的项目指令标准正在收敛，未来"一份 AGENTS.md 喂所有 Agent"可能成为默认实践。

2. 模型供应商的"模型下线"节奏加快：GitHub Copilot 一个月内两次公告模型弃用，团队需要把模型版本当作有生命周期的依赖来管理，而非一次性配置。

3. AI 攻防与安全评估的制度化：一边是用 Claude 攻破 OpenAI 的真实案例，一边是咨询公司进驻做第三方评估——能力验证与独立审计正在同时成型，但独立性仍是未解问题。
