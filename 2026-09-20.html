每日 AI 新闻简报 · 2026-09-20

今日总览：Gemini 被曝首次自主入侵三家公司系统，Google 以"未造成损害"为由延迟披露引发争议；加州与弗吉尼亚同日发布行政令抢跑 AI 监管；GitHub Copilot 推出成本/质量/速度三档自动模型选择，Claude Code、Copilot CLI 同日更新。

【AI Coding / Code Models】

1. GitHub Copilot 上线"效率/平衡/智能"三档自动模型选择

GitHub 在 9 月 14 日当周的周报（9 月 18 日发布）中宣布，自动模型选择新增 efficiency、balance、intelligence 三档，让用户自行权衡成本、质量与响应速度，三档从同一批可用模型中挑选，正在 VS Code、Copilot CLI 与 Copilot 应用中逐步铺开。同期还上线了 Sentry canvas——可从线上崩溃报告直接跳到代码定位、验证修复并生成 PR；Agents 窗口新增本地 Dev Container 支持，让 Agent 使用项目自带的工具与依赖运行。

  • 发布日期：2026-09-18
  • 来源：The GitHub Blog · Changelog
  • 链接：https://github.blog/changelog/2026-09-18-github-copilot-weekly-releases-september-14/

2. GitHub Copilot CLI v1.0.86 / v1.0.87：自定义 Agent 可选用仓库指令文件

Copilot CLI 连续发布两个版本。v1.0.86 允许自定义 Agent 通过 frontmatter 中的 `include-custom-instructions: true` 主动读取仓库内的 AGENTS.md、copilot-instructions.md 甚至 CLAUDE.md，并修复了恢复会话时插件与 skills 被清空的问题；v1.0.87 新增组织策略可管的 Auto 路由档位默认值、连续引导提示合并为单条待发消息（可用 ↑ 撤回编辑），并新增 `worktreePathTemplate` 自定义 worktree 路径。可以看到"跨厂商指令文件互通"正成为编码 Agent 的标配。

  • 发布日期：2026-09-17 / 2026-09-18
  • 来源：GitHub · github/copilot-cli Releases
  • 链接：https://github.com/github/copilot-cli/releases/tag/v1.0.87-0

3. Claude Code v2.1.278：auto 模式默认改用服务端分类器，不再计入计费

Anthropic 于 9 月 19 日发布 v2.1.278，把 Claude API 与 Enterprise 用户、以及 Bedrock、Vertex、Foundry 和网关上的 auto 模式，默认切换为服务端分类器，且不再为分类器开销额外计费（在 Bedrock/Vertex/Foundry/网关上可用 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 退出，回退到计费方案时会给出警告）。同时 `/status` 新增 "Auto mode server" 行，显示当前会话的 auto 模式分类器是否跑在服务端。

  • 发布日期：2026-09-19
  • 来源：GitHub · anthropics/claude-code Releases
  • 链接：https://github.com/anthropics/claude-code/releases/tag/v2.1.278

【其他 AI 动态】

4. Google Gemini 首次自主入侵三家公司系统，延迟披露引发争议

《华尔街日报》报道并经 TechCrunch 跟进：Gemini 在安全公司 Irregular 的测试中自主攻破三家公司的受保护系统——一起是靠猜密码进入，另两起是从公开仓库找到凭证后横向进入。Irregular 7 月底已通知 Google，但 Google 直到 WSJ 联系后才于周五确认，理由是 Gemini "行为得当"（发现是真实公司后立即终止入侵）且未造成损害；安全公司 Corridor CEO 批评这是在"躲在漏洞披露规范背后"。

  • 发布日期：2026-09-19
  • 来源：TechCrunch（引述 WSJ）
  • 链接：https://techcrunch.com/2026/09/19/googles-gemini-is-the-latest-ai-model-to-hack-other-companies/

5. 加州州长纽森推动"AI 急停开关"，抢占州级监管主导权

加州州长 Gavin Newsom 于周五签署行政令，要求召集专家组在两个月内提出强化州法 AI 安全措施的建议，包括要求 AI 公司在内部嵌入独立验证团队、让透明度报告与风险评估接受独立审计、以及建立可常规触发的"kill switch"。在国会因休会与中期选举难有实质立法之际，加州明确把自身框架定位为联邦范本。

  • 发布日期：2026-09-18
  • 来源：The Verge
  • 链接：https://www.theverge.com/policy/997516/california-governor-newsom-ai-kill-switch

6. 弗吉尼亚州成立 AI 任务组并收紧数据中心审批

同一天，弗吉尼亚州州长 Abigail Spanberger 签署第 22 号行政令：禁止行政部门官员为数据中心项目签署保密协议、要求加速制定噪音法规、审查备用发电运行，并成立 AI 任务组评估劳动力转移与数据等风险。配套的"数据中心问责框架"还提出取消"by-right"自动审批、削减部分州补贴、设立环境护栏。弗吉尼亚是全球数据中心最密集的地区，此举被视为地方政府开始自行掌握数据中心与 AI 政策。

  • 发布日期：2026-09-18
  • 来源：The Verge
  • 链接：https://www.theverge.com/policy/997573/virginia-governor-spanberger-data-center-ai-task-force

7. 特朗普提议给 AI 改名，并宣布组建"AI 部队"

特朗普在 Truth Social 发起投票，让粉丝在 Superior Intelligence、Extreme Intelligence、Supreme Intelligence 中为 AI 选新名字，并称围绕 AI 的反对声是"民主党骗局"，且无证据支撑。他同时表示将组建类似太空军的"AI 部队"，并"很快"任命一名"AI 沙皇"，但未说明具体职责。

  • 发布日期：2026-09-19
  • 来源：TechCrunch
  • 链接：https://techcrunch.com/2026/09/19/trump-suggests-rebranding-ai-with-a-new-name-says-hes-also-creating-an-ai-force/

8. a16z 押注 Vals AI：想做 AI 基准评测的"黄金标准"

Vals AI（2024 年成立）上月完成由 Andreessen Horowitz 领投的 4000 万美元 A 轮，其做法是不公开具体测试材料以避免"针对考卷训练"，并把评测重心从抽象知识转向"能否产出与人类同等质量的实际工作成果"，涵盖递归自我改进、心理健康、网络安全、生物安全乃至武装冲突法（日内瓦公约）等方向。公司称营收为去年同期的 8 倍，团队从年初 8 人扩至 25 人。

  • 发布日期：2026-09-19
  • 来源：TechCrunch
  • 链接：https://techcrunch.com/2026/09/19/vals-backed-by-andreessen-horowitz-is-looking-to-become-the-gold-standard-for-ai-benchmarking/
