🤖 AI Coding / Code Models

1. htmx 4.0 正式发布

  • 摘要：轻量级前端框架 htmx 发布 4.0 大版本，带来全新的组件模型、增强的 WebSocket 支持和更简洁的 API。htmx 主张"用 HTML 表达行为"，避免过度依赖 JavaScript 框架，在 AI 辅助开发浪潮中成为开发者回归简洁架构的重要选择。
  • 日期：2026-08-28
  • 来源：htmx 官方博客
  • 链接：https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released

2. Talos：带确定性权限内核的 AI Coding Agent

  • 摘要：Talos 是一个开源 AI 编程代理，核心创新在于每次工具调用都经过确定性策略门控——仅对精确参数授予一次、30 秒有效期的权限，并将裁决写入不可篡改的审计日志。该设计直接回应了"MCP Server 以用户身份运行、拥有完整权限"的安全隐患，为 AI Agent 安全操作提供了可验证的范式。
  • 日期：2026-08-28
  • 来源：Talos 官网 / Hacker News
  • 链接：https://talos-agent.ch/

3. Terminal-Bench-Science 发布：评估 AI 编程代理的科研能力

  • 摘要：斯坦福大学团队在 Terminal-Bench 基础上推出 Terminal-Bench-Science 0.1，用 70 项真实科研工作流（生命科学、物理、地球科学、数学、工程）评估 AI Agent 编程能力。当前最强模型 Claude Opus 5 仅达 30% 解析率，GPT-5.6 为 22.4%，凸显 AI 在科学编程领域仍有巨大提升空间。
  • 日期：2026-08-28
  • 来源：Terminal-Bench-Science 官网
  • 链接：https://www.terminal-bench-science.ai/announcement

6. Google 发布 Gemini 3.5 Transcribe 智能语音转写

  • 摘要：Google 推出 Gemini 3.5 Transcribe，将大语言模型的语义理解能力融入语音转文字，可同时完成转录和智能标注、摘要、翻译等任务，大幅超越传统 ASR 方案。该模型面向医疗、法律、媒体等专业场景，HN 上获得 350 分。
  • 日期：2026-08-26
  • 来源：Google Blog
  • 链接：https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5-transcribe/

7. Anthropic 预览 Model Hardware Standard（MHS）

  • 摘要：Anthropic 发布 MHS 研究预览版，一套让 AI Agent 安全操作物理设备（显微镜、液体处理器、机械臂等）的共享规范。MHS 可将硬件集成时间从数周缩短至数小时，并支持 Agent 自主编排全天候实验。目前已与 HHMI Janelia 等科研机构合作。
  • 日期：2026-08-27
  • 来源：Anthropic 官方博客
  • 链接：https://www.anthropic.com/news/model-hardware-standard-research-preview
