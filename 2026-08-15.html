🧠 AI Coding / Code Models

1. GLM-5.3 发布：前沿代码模型，具备涌现级网络能力

智谱（Z.ai）发布 GLM-5.3，在编程和网络安全领域展现出强大的涌现能力，成为当前代码能力最强的前沿模型之一。该模型在多项编程基准测试中取得领先成绩，引发 HN 社区热议（1022 分，504 条评论）。

📅 2026-08-14 | 来源：Z.ai

🔗 https://z.ai/blog/glm-5.3

2. OpenAI Codex 登陆 Linux 桌面预览版

OpenAI 宣布 Codex 现已支持 ChatGPT Linux 桌面应用（预览版），Linux 开发者可直接在桌面环境中使用 Codex 进行代码编写、调试和项目管理。此举填补了 Linux 平台 AI 编程助手的重要空白。

📅 2026-08-13 | 来源：OpenAI Community

🔗 https://community.openai.com/t/codex-in-chatgpt-desktop-app-for-linux-is-now-in-preview/1390027

3. Zed 发布 Delta：多智能体协作编程环境

Zed 编辑器团队推出 Delta——一个支持多 AI 智能体同时协作编程的全新环境。开发者可指派多个 Agent 并行处理代码审查、重构和测试等任务，实现真正的 AI 团队协作开发。

📅 2026-08-12 | 来源：Zed Blog

🔗 https://zed.dev/blog/introducing-delta

4. Google 发布 Gemini 3.7 Flash：最强「工作马」模型

Google 推出 Gemini 3.7 Flash，定位为面向编程和 Agent 场景的最强高效模型。在保持低延迟的同时大幅提升推理能力，专为高频调用和 Agent 工作流优化。

📅 2026-08-13 | 来源：Google Blog

🔗 https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/

DeepSeek 发布 V4 Pro 0813 版本，已通过 OpenRouter 提供 API 访问。该版本在多语言推理和长上下文理解方面有显著提升，定价具有竞争力。

📅 2026-08-12 | 来源：OpenRouter

🔗 https://openrouter.ai/deepseek/deepseek-v4-pro-0813

6. Qwen 3.8 系列发布：27B 与 2.4T 双版本

阿里巴巴通义团队发布 Qwen 3.8 系列，包括 27B 高效模型和 2.4T 超大参数版本。27B 版本在同等规模模型中表现突出，适合本地部署；2.4T 版本采用 MoE 架构，在多项基准上接近 GPT-5.6 水平。

📅 2026-08-14 | 来源：HuggingFace / Qwen

🔗 https://huggingface.co/Qwen/Qwen3.8-27B-FP8

7. Cerebras 联手 OpenAI 推出 GPT-5.6 Sol 极速模式

Cerebras 与 OpenAI 合作推出 Ultrafast Mode，GPT-5.6 Sol 在 Cerebras 芯片上实现高达 750 tokens/秒的输出速度，比 Claude Fable 5 快 11 倍，完成 Humanity's Last Exam 全部 2500 道题仅需 11 小时。

📅 2026-08-13 | 来源：Cerebras Blog

🔗 https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai
