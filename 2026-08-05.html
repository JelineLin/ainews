🤖 每日 AI 新闻简报 · 2026年8月5日

今日总览： 代码模型领域 DeepSeek V4 首次完成单卡 AMD MI300X 推理验证，Flowise 因 Coding Agent 崛起而宣布关停。政策方面，白宫将开源模型排除在 AI 能力测试框架之外，德州暂停新数据中心审批。AI 安全与用工合规问题持续发酵。

【AI Coding / Code Models】

1. DeepSeek V4 Flash 成功在单张 AMD MI300X 上运行

开发者发布开源项目，首次实现 DeepSeek V4 Flash 模型在单个 AMD MI300X GPU 上的完整推理部署。项目采用 Apache 2.0 许可，已获 94 星，为 AMD 生态下的高密度 MoE 推理提供了重要参考实现。

  • 日期： 2026-08-04
  • 来源： GitHub (ryanzhou)
  • 链接： https://github.com/ryanzhou/deepseek-v4-flash-mi300x

2. Flowise 宣布关停，归因于 Coding Agent 的崛起

知名低代码 AI 应用构建平台 Flowise 正式宣布停止运营。团队声明指出，随着 Claude Code 等编码代理能力的快速提升，传统低代码工作流在应对复杂任务时已触及天花板，开发者正大量转向 AI 编程助手。代码库将归档为 Apache 2.0 许可，社区可自行 fork。

  • 日期： 2026-08-05
  • 来源： FlowiseAI
  • 链接： https://flowiseai.com/sunset

3. Kimi K3 AgentENV 技术深扒：微 VM 真的能在 100ms 内 Fork 吗？

GenseeAI 发表深度技术文章，分析 Kimi K3 使用的 AgentENV 沙箱架构。文章详细解释了 Firecracker 微 VM 的脏内存捕获路径、OverlayBD 的懒加载机制，并与 TClone 的 CoW 直接共享方案进行对比。该分析澄清了 AgentENV 的 fork 延迟受脏页数量线性影响，并非真正的"100ms 恒定 fork"。

  • 日期： 2026-08-03（扩展时间范围至 72 小时）
  • 来源： GenseeAI
  • 链接： https://www.gensee.ai/blogs/inside-agentenv-dirty-memory-microvm-fork.html

【其他 AI 动态】

4. 白宫将开源模型排除在 AI 能力测试新框架之外

Axios 报道，白宫最新发布的 AI 高级能力测试框架明确将开源模型排除在外。该框架旨在评估前沿 AI 系统的潜在风险，但仅覆盖闭源商业模型。此举引发开源社区对"监管双轨制"的担忧，认为可能抑制开源 AI 生态的发展。

  • 日期： 2026-08-04
  • 来源： Axios
  • 链接： https://www.axios.com/2026/08/04/trump-ai-framework-open-models

5. OpenAI 因歧视美国工人与美国司法部达成和解

美国司法部宣布，OpenAI 就招聘过程中歧视美国工人达成和解协议。这是 AI 行业在用工合规方面的重要标志性案件，表明监管机构正加强对 AI 公司招聘实践的审查力度。

  • 日期： 2026-08-04
  • 来源： 美国司法部
  • 链接： https://www.justice.gov/opa/pr/civil-rights-division-secures-settlement-openai-discriminating-against-us-workers

6. Waymo 在达拉斯全面开放自动驾驶服务

Waymo 官方宣布其自动驾驶出租车服务在达拉斯向所有公众开放。这是 Waymo 继旧金山、洛杉矶、凤凰城之后，在德州最大城市的全面铺开，标志着自动驾驶出行服务在美国南部的加速扩张。

  • 日期： 2026-08-04
  • 来源： Waymo 官方博客
  • 链接： https://waymo.com/blog/shorts/dallas-open-to-all/

7. 德州州长叫停新建数据中心，要求全面审计

德州州长 Greg Abbott 宣布暂停该州所有新数据中心的审批，并要求对现有数据中心进行能源消耗与水资源使用审计。此举直接回应 AI 算力扩张带来的基础设施压力，可能影响多家科技巨头在德州的大型数据中心建设计划。

  • 日期： 2026-08-04
  • 来源： TechCrunch
  • 链接： https://techcrunch.com/2026/08/04/texas-halts-new-data-centers-as-governor-calls-for-audits/
