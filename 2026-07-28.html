【AI Coding / Code Models】

1. Cursor Bridge：在 Cursor 订阅上运行 Claude Code 编程 Agent

> 开源项目 Cursor Bridge 发布，允许开发者利用已有 Cursor 订阅运行 Claude Code 会话，无需额外付费。该项目用 Rust 实现单一二进制文件，零配置即可使用。这反映了社区对多Agent编程工作流的需求快速增长，以及用户对API成本的敏感度提高。

  • 日期： 2026年7月26日
  • 来源： GitHub
  • 链接： https://github.com/hkc5/cursor-bridge

2. Show HN：Pilot Protocol — AI Agent 发现工具与彼此的网络协议

> 开发者发布 Pilot Protocol，一个去中心化网络协议，允许 AI Agent 自动发现可用工具和其他 Agent，实现 Agent 之间的协作与互操作。该项目在 Hacker News 上获得关注，标志着 AI Agent 生态从单体走向互联。

  • 日期： 2026年7月27日
  • 来源： Hacker News
  • 链接： https://news.ycombinator.com/item?id=49070789

3. Tilde Pay：为 AI Agent 开设银行账户，让 Agent 自主支付

> 新项目 Tilde Pay 上线，为 AI Agent 提供独立的银行账户功能，让 Agent 可以自主为外部服务付费。这标志着 AI Agent 从"只会对话"向"能自主完成交易"的实用化方向迈出重要一步。

  • 日期： 2026年7月27日
  • 来源： Hacker News
  • 链接： https://my.tildepay.ai/
