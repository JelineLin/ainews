【AI Coding / Code Models】

1. Slack 推出协作式 Vibe-Coding 频道

Slack 推出专用 AI 协作编程频道，团队可在同一空间内与 AI Agent 共同编写代码，无需在多个工具和对话之间频繁切换。该功能旨在将"vibe coding"（氛围编程）从个人体验升级为团队协作模式。

  • 日期： 2026-08-20（⚠️ 使用扩展时间范围 72 小时）
  • 来源： The Verge
  • 链接： https://www.theverge.com/tech/982628/slack-code-vibe-coding-channels-launch

2. Simon Willison 发布 llm-anthropic 0.27

知名开发者 Simon Willison 发布了 LLM 工具的 Anthropic 插件 0.27 版，主要适配 Anthropic Python SDK v1.0（从 httpx 迁移至 httpx2）。值得注意的是，此次升级代码由 Claude Code 中的 Fable 5 模型自动完成，展示了 AI 辅助维护开源项目的实践。

  • 日期： 2026-08-24
  • 来源： Simon Willison's Blog
  • 链接： https://simonwillison.net/2026/Aug/24/llm-anthropic/

5. Stripe 以 75 亿美元收购 AI 网关 OpenRouter

  • 来源： The Verge / NYT
