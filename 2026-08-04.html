每日 AI 新闻简报 | 2026年8月4日

今日总览： 代码模型领域热度持续升温，Epoch AI 发布 MirrorCode 长程编码基准测试；Hoplite 和 JetBrains 各有新动作。AirLLM 实现单卡4GB GPU运行70B推理引发热议，欧盟AI法规正式生效。

【AI Coding / Code Models】

1. Epoch AI 发布 MirrorCode 基准测试：AI 能独立完成多大的软件项目？

Epoch AI 发布全新长程编码基准 MirrorCode，测试 AI 在无法访问原始源码的情况下，能否端到端完整重写整个软件项目。该基准旨在衡量 AI 编程系统的真实自主能力，而非简单的代码补全或函数生成。结果显示，前沿模型已能完成中等规模项目的完整重写，但大型项目仍有显著差距。

  • 发布日期： 2026年8月3日
  • 来源： Epoch AI
  • 原文链接： https://epoch.ai/MirrorCode

2. Hoplite (YC S26) 上线：让云端 Coding Agent 部署变得轻松

YC S26 批次项目 Hoplite 正式公开亮相，主打"毫不费力的云端 Coding Agent 体验"。开发者无需手动配置云基础设施即可快速部署和运行 AI 编码代理，在 Hacker News 上获得 50 分关注。该产品瞄准的是当前 AI 编码工具部署复杂、环境配置繁琐的痛点。

  • 发布日期： 2026年8月3日
  • 来源： Hacker News (Hoplite)
  • 原文链接： https://hoplite.sh

3. JetBrains 发布 Kotlin AI Coding Agent 基准测试（扩展范围，发布日期：2026年7月底）

JetBrains 推出面向 Kotlin 生态的 AI Coding Agent 基准测试，用于评估 AI 编码代理在真实世界 Kotlin 任务上的表现。该基准包含精心设计的 Kotlin 编程任务，涵盖 Android 开发、后端服务等场景，并开放了排行榜供社区对比不同模型表现。*（注：因最近24小时该领域报道不足，本条扩展至72小时范围。）*

  • 发布日期： 2026年7月31日
  • 来源： JetBrains Blog
  • 原文链接： https://blog.jetbrains.com/kotlin/2026/07/introducing-the-kotlin-benchmark-evaluate-ai-coding-agents-on-real-world-kotlin-tasks/

【其他 AI 动态】

4. AirLLM：单张 4GB GPU 即可运行 70B 大模型推理

开源项目 AirLLM 在 GitHub 上已获超 27,000 Stars，它通过创新的内存优化和分片推理技术，让开发者可以在仅有 4GB 显存的 GPU（甚至消费级显卡）上运行 70B 参数的大模型。该项目大幅降低了超大模型推理的硬件门槛，引发社区热议。

  • 发布日期： 2026年8月3日（HN热门）
  • 来源： GitHub
  • 原文链接： https://github.com/lyogavin/airllm

5. Nightcrawler：在智能手机上运行的本地 AI 渗透测试 Agent

开源项目 Nightcrawler 发布，它是一款完全在本地运行的 AI 渗透测试 Agent，可直接部署在智能手机上。该工具利用端侧大模型执行安全测试任务，无需将数据传输到云端，在保护隐私的同时实现移动端安全审计。目前已获 357 Stars。

  • 发布日期： 2026年8月3日
  • 来源： GitHub (garagehq)
  • 原文链接： https://github.com/garagehq/nightcrawler/

6. AI 将 COBOL 程序迁移到 Java，连 bug 也一起搬过来了

arXiv 新论文提出一种名为"Locksmith Loop"的智能体测试合成方法，用于将遗留 COBOL 程序迁移到 Java。在三个案例研究中（覆盖 430 到 4,114 行源码），该方法实现了接近完全的分支覆盖。但研究发现，AI 生成的 Java 代码在确定性校验下完美匹配了 COBOL 参考实现——包括其中原有的 bug。

  • 发布日期： 2026年7月30日
  • 来源： arXiv
  • 原文链接： https://arxiv.org/abs/2607.28271

7. EU AI 法规正式生效：AI 生成内容强制标签

欧盟《人工智能法案》中的关键条款于 2026年8月2日起正式执行，要求所有 AI 生成的文本、图像、音频和视频内容必须明确标注"AI 生成"标签。该规定覆盖在欧盟市场运营的所有企业，违反者将面临严厉处罚。此举标志着全球 AI 监管迈入实质性执行阶段。

  • 发布日期： 2026年8月2日
  • 来源： Euronews
  • 原文链接： https://www.euronews.com/my-europe/2026/08/02/ai-generated-label-becomes-mandatory-in-the-eu-for-companies
