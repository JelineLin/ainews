【AI Coding / Code Models】

1. 微软发布 MAI-Code-1.1-Flash：更强、更快、成本仅四分之一

发布日期：2026-08-11（扩展范围：24–72h）

微软 AI 团队正式推出 MAI-Code-1.1-Flash，相较 6 月发布的 1.0 版本，代码质量提升、Token 效率提高 25%、成本降至四分之一。该模型已在 GitHub Copilot 中上线，Terminal-Bench 2.1 提升 22%，.NET 任务提升 15%，代码存活率上升 4%，回访率增加 9%。

来源： Microsoft AI Blog

链接： https://microsoft.ai/news/mai-code-1-1-flash-br-better-faster-at-a-quarter-of-the-cost/

2. YC 孵化项目 Bullet 发布：号称 SWE-Bench 95.8% 的极速 Coding Agent

发布日期：2026-08-13

Y Combinator 最新一期孵化项目 Bullet 正式公开，宣称在 SWE-Bench 上达到 95.8% 的验证成绩。核心卖点在于极低延迟：通过智能路由（简单任务走快速模型）、并行执行和去重拦截等机制，大幅减少等待时间。提供 CLI 和桌面端，免费试用。

来源： Bullet 官网

链接： https://www.codewithbullet.com

3. Cursor 推出 Design Mode：用视觉提示直接指挥 Agent

发布日期：2026-08-12（扩展范围：24–72h）

AI 编程工具 Cursor 发布 Design Mode 功能，允许用户通过视觉提示（visual prompts）直接指挥 AI Agent，让设计稿、截图和线框图成为编程 Agent 的输入。这一模式大幅降低了从设计到代码的转换门槛。

来源： Cursor Blog

链接： https://cursor.com/blog/design-mode

7. 报告显示：AI 生成 3D 模型泛滥，但几乎无人购买

发布日期：2026-08-13

3D 模型平台 CGTrader 发布市场趋势报告，指出平台上六分之一的模型为 AI 生成，但这些 AI 资产仅贡献了 1/90 的收入。买家用钱包投票——AI 生成内容在信任度上仍远不及人工创作，行业需重新思考 AI 生成内容的真实价值。

来源： 404 Media

链接： https://www.404media.co/ai-generated-3d-models-flood-market-but-almost-no-one-is-buying-them/

【值得关注的趋势】

1. 编码 Agent 全面爆发：从微软、Cursor 到 YC 新秀 Bullet 和开源 Hax，编码 Agent 正在从"能用"走向"好用"。延迟优化、成本控制和视觉交互成为差异化竞争焦点。

2. AI 公司大并购时代开启：Anthropic 60 亿美元收购 Decart 和 Cognition 400 亿美元估值，表明头部 AI 公司正通过资本运作加速技术布局，行业整合加速。

3. AI 生成内容的信任危机：CGTrader 数据揭示了一个残酷现实——AI 虽然能低成本大量生成内容，但市场接受度远未跟上供给速度。质量和信任仍是 AI 商业化的重要瓶颈。
